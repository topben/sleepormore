# 同床異夢 · Sleep or More

3D 情侶同床模擬小遊戲(three.js)。你和另一半——穿著睡衣的毛絨玩具小熊與垂耳兔——躺在同一張床上,今晚的目標是 **😴 好好睡覺** 還是 **💞 親熱**?對方也有自己的祕密目標。12 回合(22:00 → 06:00)內達成目標——太粗魯會被踢下床、棉被會被搶、手臂會被枕到發麻。

設計規格見 `docs/DESIGN.md`(§14 是實作時的補充與平衡調整),3D 規格見 `docs/SCENE-RIG.md`。

## 怎麼玩

1. 選角色(男方睡左邊、女方睡右邊),看今晚的目標與小撇步。
2. 每回合選一個動作 → 對方行動 → 時間流逝 40 分鐘。
3. **閉眼**才能睡、也可能被當成睡著了;**張眼**才看得到對方的心情、火氣、睡意。
4. 標著「按住」的動作要蓄力:按住按鈕(或空白鍵),在綠色區放開。
5. 從對方的話與行為猜對方想要什麼;天亮時揭曉。

## 讓遊戲更好上手的設計

- **💡 建議列**:每回合依「你看得到的資訊」建議下一步,並讓建議的按鈕發光(可在設定關閉)。
- **目標進度**:睡眠分數 x/7 或親密度 x/100,附「來得及 / 有點趕 / 來不及了」。
- **直覺**:對方說出、做出透露目標的事時記成線索,狀態卡顯示「對方好像想…」。
- **力道條**:直接在動作按鈕上按住就能蓄力;只是點一下不會送出太輕的動作,而是打開力道條等你按住。設定裡有「自動力道」可以跳過。
- **不能做的動作**會變灰,點一下說明原因;按鈕外框顏色表示會不會吵醒對方。
- 開局在你的角色頭上標示「你」;結局卡附「下次可以試試」的提示並揭曉對方目標。
- 手機直式可玩(按鈕 ≥ 44px),快捷鍵:空白鍵 = 蓄力、E = 閉眼/張眼、H = 說明、Esc = 取消。

## 組合結局(64 種)

每晚依兩人的實際玩法,各判定一種「睡姿人格」(拉棉被大師、悄悄話高手、無尾熊、哄睡保母、秒睡機器、裝睡演員、翻身陀螺、冰山邊緣人);**你 × 對方 = 64 種組合結局**,分成普通 / 稀有 / 超稀有 / 傳說。結局卡可以產生一張**結局圖卡**(結局當下的 3D 畫面 + 組合 + 稀有度)直接分享到 LINE / IG,或下載圖片;開始畫面的 🏆 圖鑑記錄收集進度。細節見 `docs/DESIGN.md` §14.7–14.8。

## 困難模式

開始畫面選「🔥 困難」:親熱分成 **⏱️ 立即親熱**(02:00 前要達成)和 **🌅 早上親熱**(先睡飽,04:40 以後才算,太早滿了只算平手);睡覺要**舒服地睡著**才算分 —— 體溫會亂跳、半夜會變冷,親密度沒互動也會掉,而且男女體質不同:🐻 小熊怕熱、🐰 垂耳兔怕冷也比較需要安全感。對方也照自己的體質與種類行動(熱了把棉被踢給你、立即親熱的對方過了兩點就放棄、早上親熱的對方天亮才醒來撒嬌)。簡單模式的規則完全不變。細節見 `docs/DESIGN.md` §15。

## 多語系

繁體中文、简体中文、日本語、한국어、Tiếng Việt、English、Español。預設依 `?lang=` → 上次選擇 → 瀏覽器語言;可在開始畫面或設定中隨時切換。字典在 `src/i18n/<語系>/{game,ui}.ts`,結構以繁中為準(`pnpm test` 會檢查每個語系的鍵、句數與佔位符)。

## 開發

```sh
pnpm install
pnpm dev        # http://localhost:5173
pnpm test       # 遊戲邏輯、勝率模擬、多語系一致性測試
pnpm build      # 型別檢查 + 靜態打包到 dist/
```

```
src/
  main.ts        組裝:遊戲邏輯 + 3D 場景 + UI,回合分段播放
  game/          純 TS 規則(可重現的亂數、動作、結算、對方 AI、結局、建議)
  scene/         three.js 場景(毛絨玩具角色、橡皮管手臂、鋪棉棉被、漫畫符號、接觸陰影、合成音效)
  ui/            純 DOM + CSS 介面(HUD、力道條、對話泡泡、畫面)
  i18n/          7 種語言的字典
tests/           vitest
```

部署:Vercel(自動偵測 Vite,零設定)。流量統計用 Vercel Web Analytics(`@vercel/analytics`),要在 Vercel 專案的 Analytics 分頁啟用後才會有資料。
